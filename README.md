# Durga Prasad Sahoo Portfolio

A conversational portfolio website for Durga Prasad Sahoo, a Full-Stack AI Engineer, where navigation and search return portfolio sections as chatbot-style responses.

For GitHub Pages, the Vite base path and React Router basename are configured for this repository's `/Porfolio/` URL. Build with `npm run build` and publish the generated `dist` directory using GitHub Pages.
