# Durga Prasad Sahoo Portfolio

A conversational portfolio website for Durga Prasad Sahoo, a Full-Stack AI Engineer, where navigation and search return portfolio sections as chatbot-style responses.

Deployment paths are configured per host: Vercel builds at `/`, while GitHub Pages uses this repository's `/Porfolio/` path. Redeploy after pushing changes; Vercel uses its built-in `VERCEL=1` environment variable to select the root path.
